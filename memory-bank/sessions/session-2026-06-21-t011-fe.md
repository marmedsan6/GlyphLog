# Sesión 2026-06-21 — T-011-FE: Página de colección (Frontend)

## Goal

Implementar la página de colección del usuario en `apps/web`, incluyendo listado paginado, filtros por tipo, estados de carga/vacío/error/éxito y actualización automática tras crear una entrada.

## Discoveries

- El tipo autogenerado `api.d.ts` no reflejaba la paginación; regenerarlo con `pnpm --filter web generate-types` funcionó sin problemas y creó `EntryListItem` y `PaginatedEntryResponse`.
- Las imágenes de portada se sirven desde `/uploads` en la raíz del backend, mientras que `VITE_API_URL` apunta a `/api/v1`. Fue necesario añadir `VITE_API_BASE_URL` y configurar el proxy de Vite para `/uploads`.
- `vite.config.ts` usaba `defineConfig` de `'vite'`, lo que impedía que `tsc -b` reconociera la sección `test`. Cambiar a `'vitest/config'` resolvió el problema.
- Los tests de TanStack Query requieren un `QueryClient` aislado con `retry: false` para evitar flakiness.
